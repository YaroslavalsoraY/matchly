# Сквозные тесты интерфейса

Скрипты Playwright прогоняют реальный браузер (Chromium) по всему пользовательскому пути:
регистрация, онбординг с фото, лента и лайк, взаимный матч, матчи и их разрыв, редактирование анкеты,
админ-панель (статистика, пользователи, интересы, настройки), мобильная ширина 400px.

Требования: Node.js 18+ и запущенное приложение на `http://localhost:8080` с демо-данными.

```bash
cd e2e
npm install
npm run install-browser   # скачивает Chromium (~150 МБ), один раз
npm test                  # e2e.js: 18 шагов, в конце удаляет созданных тестовых пользователей
npm run shots             # shots.js: обновляет скриншоты в docs/screenshots
```

На Windows команды те же (PowerShell или cmd).
